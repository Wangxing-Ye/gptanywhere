# GPTAnywhere 产品需求

模型、语言覆盖和设备性能必须经过技术验证后才能锁定。

## 品牌

| 用途 | 英文 | 中文 |
| --- | --- | --- |
| 应用名 | GPTAnywhere | GPTAnywhere |
| 副标题 | Offline Chat, Text, Photo & Voice Translator | 离线对话，以及文字、图片与语音翻译 |
| 宣传语 | Chat and translate anywhere. Even offline. | 随处对话、翻译，无需联网。 |

界面名称是 GPTAnywhere，中文界面也显示这个名字。没有免费版和 Pro，不做购买、订阅或广告。启动页和关于页展示应用名；宣传语只用于首次引导和介绍页。商店字段按平台长度截取，不把完整副标题硬塞进受限字段。宣传语对应模型准备完成后的离线能力。首次启动必须说明模型准备步骤。

内部工程名 `translateanywhere`。Android 包名和 iOS Bundle ID 都是 `dev.local.gptanywhere`。这是本地标识，不是商店包名，也不从上架前未确认的域名推导。正式上架前另做名称可用性检查。本次未做商标、域名和商店重名核查。

## 目标与边界

为 Android 和 iOS 提供本机完成的自由对话，以及文字、拍照或导入图片、录音或导入音频的翻译，还有可选的本机朗读。定位是简洁界面、隐私、旅行和日常跨语言沟通。

- 不要求注册。模型下载和主动更新需要网络。模型齐备后，核心功能可长期离线使用。
- 无逐次联网鉴权，无静默云端翻译回退。
- 新安装且未准备模型的设备不能承诺直接离线使用。路径有两条：首次联网下载，或通过系统文件选择器导入官方离线模型包。
- 首发先在 Android 做技术验证。OnePlus 6T（8GB/128GB）是低性能探索设备，另测一台较新 Android 和一台 8GB iPhone。iOS 必须有真实构建和真机验收。
- 完全离线安装包的再分发须另行验证许可证和商店限制。

首发范围：离线对话，文字、图片和语音翻译，语言能力矩阵、离线朗读、历史与收藏、术语表、模型管理、导出、可访问性和错误恢复。

不作为首发阻塞项：连续同传、视频字幕、手写识别、PDF 整本解析、照片背景修复。普通录音翻译不承诺实时。

## 对话

- 底部第一项，打开应用时缺省进入。使用当前文字模型自由回复，不使用翻译提示。
- 最近几轮放进一次调用。上下文放不下的更早轮次丢掉。对话只留在这次进程的内存里。
- 可以发送文字，也可以从相册、拍照、录音或导入音频加入内容。拍照不经过图片页的裁剪。
- 图片和语音的识别语言固定为简体中文。识别出的文字只作为用户消息，不得当作程序指令执行。
- 没有看图文件的模型先识别图片里的文字，包括 Qwen3-1.7B、Gemma 3 1B、LFM2.5-1.2B、LFM3-1.7B、MiniCPM5-1B 和 MiniCPM5-2B。列出看图文件的模型使用该模型自己的看图文件，包括 LFM2.5-VL-1.6B 和 MiniCPM-V 4.7 1B。看图文件还没准备好时，不改走文字识别。
- 对话页不放语言菜单。思考模式缺省关闭，并用推理配置关闭。
- 生成可以取消。取消必须传到原生任务，过期回复不得覆盖新消息。

## F01 文字翻译

- 自动识别或手动选择源语言，选择目标语言，交换语言，记住最近语言组合。
- 输入、粘贴、清空、编辑、长按选择、复制结果、系统分享。
- 翻译由按钮触发，避免每次按键都跑模型。支持流式显示、取消生成、重新翻译。
- 原文和译文分区展示，保留段落、数字、网址和品牌名。
- 长文本按句子和段落切分，并保留有限相邻上下文。长度按模型 token 预算限制，不以字符数代替 token 数。
- 原文和译文朗读是否可用，取决于对应 TTS 语言包。
- 语言识别置信度低时提示用户选择语言。不伪造模型翻译置信度。

## F02 拍照与图片翻译

- 拍摄、系统相册、旋转、裁剪、方向校正和必要缩放。
- OCR 输出文字块、阅读顺序和标准化坐标。用户可修正识别文本后再翻译。
- 默认双语文字视图。另提供图片原文视图，以及点击文字块查看翻译。
- 首发可做简单遮罩文字覆盖，含自动换行和缩放。复杂表格和艺术字体不保证还原版式。
- 不按每一行机械翻译。文章合并成段落，菜单按条目，保留块 ID 与译文的映射。
- 拍摄预览不持续调用 LLM。用户确认图片后再处理。限制解码分辨率，避免超大图占满内存。
- 选择语言时标明 OCR 不支持的文字体系。LLM 支持不等于 OCR 支持。

## F03 录音与音频翻译

- 按住说话，以及点击开始和停止。展示录音状态、计时和可访问的停止按钮。
- 源语言以手动选择为先，自动识别为可选项。
- 用 VAD 切分有效语音，保留少量前后缓冲，避免吞掉首尾。静音不生成虚构文字。
- ASR 先生成可编辑原文，再进入统一翻译服务。
- 结果含原文、译文、复制、收藏、重译和可选朗读。
- 导入音频时校验类型、解码失败和时长，并按所选模型要求转换采样率和声道。
- 长录音分段排队并保留时间戳。可取消，并保留已完成部分。第一版低端机单次录音建议 30 秒。导入长音频允许分段，但要提示耗时。
- 来电或音频焦点丢失时暂停并释放麦克风。不在后台静默继续录音。

## F04 语言管理

首批候选：简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、葡萄牙语。

- 简体和繁体是输出选项，不宣称是两种语音。字形转换必须经过本地验证，并测试地区词汇。
- 每种语言分别记录 `text_translation`、`ocr`、`asr`、`tts`、`auto_detect` 和对应模型。每个语言对另记录验证状态。
- 首发先让中英双向在文字、图片和语音三种翻译入口通过验收，再扩大候选语言。其余语言不能只凭模型说明书标成正式支持。
- OCR 首选引擎覆盖中文、日文、韩文、天城文和拉丁文字。不能据此宣称支持阿拉伯文、泰文等图片识别。
- 设置中显示「可离线使用 / 需要下载 / 该模式未支持」，并列出所需空间。

## F05 历史、术语与导出

- 翻译记录默认只保存文本。可关闭、自动清理、收藏和一键删除。对话不写入这份记录，只留在当前进程的内存里。
- 图片和音频默认只做临时处理，任务结束后清理。用户明确保存时才保留附件。
- 历史可按原文和译文搜索，并按输入类型和语言筛选。
- 术语表按语言对保存源词和目标词。翻译提示使用术语；输出后检查是否遗漏。不强制替换以免造成语法错误。
- 文本和音频结果可导出 TXT。有可靠时间戳的音频可导出 SRT。图片可导出双语文本和简单覆盖图。
- 系统分享会把用户所选内容交给目标应用。不能声称分享后内容仍绝不离开设备。

## 界面

底部四项：对话、文字、图片、语音。缺省是对话。设置从顶部进入。

文字、图片和语音页顶部是源语言、目标语言和交换按钮。各页保留自己的输入。结果区放原文、译文、复制和朗读。

状态写明阶段：识别图片、识别语音、回复中、翻译中、朗读准备中，并允许取消。无法测量的任务使用不定进度，不显示虚假百分比。

设置页集中放语言与模型、品质或省电、术语表、数据管理、帮助和许可证。

不强制登录，不连续弹出多个权限框。相机只在进入拍照时申请，麦克风只在进入录音时申请。导入使用系统选择器。模型未准备好时，从设置下载，下载完成前不能显示「离线就绪」。

支持深色模式、系统字体缩放、屏幕阅读器标签和足够对比度。下载或错误状态不能只靠颜色区分。主流程不出现 GGUF、KV cache 等术语，技术信息只放在高级诊断页。

## 版本

没有免费版和 Pro 的划分，也不做购买、订阅或广告。可访问性、删除数据和错误恢复随应用提供。不设置必须联网刷新的使用额度。

## 错误

至少覆盖：模型缺失、语言不支持、文件损坏、空间不足、内存不足、识别无文本、无语音、权限拒绝、音频中断、模型加载失败、取消。

## 验收

自动测试优先覆盖任务状态、取消、模型完整性和数据迁移。翻译和对话的质量必须人工抽检，不能用固定句子断言代替。
